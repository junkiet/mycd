# MyCoinDeck Video Production Plan

**Target URL:** https://app.mycoindeck.com
**Brand:** MyCoinDeck — Unified crypto trading dashboard & social platform
**Tagline:** *Track, Analyze, and Improve Your Entire Trading Performance Unified*
**Tone:** Modern, premium, cosmic/dark theme with purple (#AB51C5) accents

---

## 1. Video Objectives

- Communicate the one-line value prop in the first 5 seconds
- Show (don't tell) the 4 supported exchanges and unified dashboard
- Drive viewers to **app.mycoindeck.com** with a clear CTA
- Match the website's cosmic / galaxy visual identity

---

## 2. Suggested Structure (60–90 seconds)

| Time | Section | What to Show | Voiceover / On-screen Text |
|------|---------|--------------|----------------------------|
| 0:00–0:05 | **Hook** | Galaxy background, logo reveal, meteor effect | "Every trade. Every exchange. One dashboard." |
| 0:05–0:15 | **Problem** | Multiple exchange tabs, scattered spreadsheets | "Tired of jumping between Binance, Bybit, OKX, Bitget?" |
| 0:15–0:30 | **Solution — Unified View** | Dashboard: Total Balance, Daily PnL, 30-Day ROI, Win Rate | "Connect read-only API keys. See everything in real time." |
| 0:30–0:45 | **Performance Analytics** | PnL charts, win rate breakdown, coin allocation | "Find your strengths. Fix your weaknesses." |
| 0:45–1:00 | **Social / Discover** | Trader profiles, leaderboard, feed posts | "Follow top traders. Learn from the best." |
| 1:00–1:15 | **Market Intelligence** | Fear & Greed index, trending coins, news feed | "Market sentiment, at a glance." |
| 1:15–1:30 | **CTA** | Sign-up screen, logo, URL | "Free forever. Setup in minutes. Start at mycoindeck.com." |

---

## 3. Must-Show Features (Checklist)

- [ ] **Hero headline + tagline** on screen
- [ ] **4 exchange logos:** Binance, Bybit, OKX, Bitget
- [ ] **Unified dashboard metrics:** Total Balance, Daily PnL, 30-Day ROI, Win Rate
- [ ] **Performance analytics:** PnL chart, win rate, ROI breakdown
- [ ] **Trader profile page:** history, positions, coin allocations
- [ ] **Leaderboard:** filter by Today / Monthly / All-Time, sorted by PnL or Volume
- [ ] **Social feed:** post, like, reshare, comment
- [ ] **Market intel:** Fear & Greed, trending coins, news
- [ ] **3-step onboarding:** Create account → Connect API → Track & improve
- [ ] **Security note:** "Read-only API keys" (trust signal)
- [ ] **CTA:** Get Started Free — no credit card, free forever

## 4. Visual / Brand Guidelines

**Colors**
- Primary: `#AB51C5` (purple/magenta)
- Background: `#000000` (pure black)
- Text: white
- Success green: `#22c55e` / Danger red: `#ef4444`

**Visual motifs to reuse**
- Animated starfield / galaxy background
- Meteor / shooting-star particle effects
- 3D constellation orb (connecting traders + exchanges)
- Gradient purple glows, glassmorphism cards
- Smooth fades, parallax scrolls

## 5. Screen-Recording Shot List

Record at **1920×1080, 60fps** from https://app.mycoindeck.com:

1. Homepage hero — slow scroll down
2. Constellation orb interaction — hover over a trader node
3. Dashboard — live metrics refreshing
4. Portfolio / analytics page — scroll through charts
5. Exchange connection flow — adding a read-only API key
6. Trader profile — PnL, positions, allocation pie chart
7. Leaderboard — switch filter Today → Monthly → All-Time
8. Social feed — scroll, like a post
9. Market intel panel — Fear & Greed, trending coins
10. Sign-up form — final CTA screen

> Tip: use a clean browser (no extensions, no bookmarks bar) and use demo data with realistic but anonymized numbers.

## 7. Localization Note

Site supports **16 languages** (EN, ZH, JA, KO, ES, FR, DE, RU, PT, IT, AR, TR, VI, TH, ID, HI). Leave **~15% safe margin** around on-screen text so localized subtitle versions can be cut without re-editing.
